# 🚀 grio — Declarative Rust UI Engine for Multimodal AI & Big Data

**grio** is an ultra-fast, declarative UI framework written in pure Rust. It generates responsive web interfaces, interactive AI Copilots, Big Data streaming grids, and REST APIs with **zero NodeJS, Webpack, or npm dependencies**.

- 📦 **Crates.io**: [https://crates.io/crates/grio](https://crates.io/crates/grio)
- 🐙 **GitHub**: [https://github.com/lecyberbill/grio](https://github.com/lecyberbill/grio)
- 📖 **Docs.rs**: [https://docs.rs/grio](https://docs.rs/grio)

---

### 🌟 Key Capabilities

1. **60 FPS Big Data Virtual Grid**: Virtualized DOM windowing rendering 100,000+ rows with client-side instant search and CSV export.
2. **Native LLM Streaming**: Real-time token streaming for local and cloud models (LM Studio, Ollama, OpenAI/vLLM) with `tok/s` and TTFT latency tracking.
3. **Curated Modern Themes**: Tokyo Night, Nord, Cyberpunk, Catppuccin Mocha, and Corporate with live hot-swapping.
4. **Desktop & Cloud Ready**: Runs as a web app, native standalone desktop window, or ~15MB Docker micro-container.
